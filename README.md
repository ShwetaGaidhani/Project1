# Project1
Maze Solver using A* Search

## Description

This project implements the **A* Search Algorithm** to find the shortest path in a maze from **Start (S)** to **Goal (G)**.
The maze is represented as a grid containing paths and walls.

## Features

* Maze representation using grid
* A* search algorithm implementation
* Uses heuristic (Manhattan / Euclidean distance)
* Finds the shortest path
* Handles unreachable goal cases

## How to Run

Run the Python file:

```
python maze_solver.py
```

## Example Maze

```
S . . #
# . . #
# . G #
```

S = Start
G = Goal

# = Wall

. = Path
